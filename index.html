Smart Waste Management

"To design a technology-driven system that enables real-time waste reporting, GPS-tagged monitoring, and AI-based waste classification for improved cleanliness and hygiene in public areas."

Problem Statement

Traditional waste management systems rely on manual inspection and irregular reporting. Authorities lack real-time visibility of waste locations, leading to delays, unhygienic conditions, and inefficient resource utilization. There is no centralized, GPS-tagged system that also automatically identifies the type of waste being reported.

Existing Systems

Manual waste collection, periodic inspections, and complaint-based reporting with no real-time map visibility.

Research Gap / Innovation

No existing system combines GPS-based reporting with automatic AI waste classification into a single unified platform.

System Methodology

Step 1

Image Upload

User captures and uploads waste photo via the web portal

Step 2

GPS Tagging

Device location auto-captured and attached to the report

Step 3 — New

AI Classification

MobileNetV2 model classifies waste into 6 categories automatically

Step 4

Admin Dashboard

Authorities view reports on live map, filter by category, mark cleaned
